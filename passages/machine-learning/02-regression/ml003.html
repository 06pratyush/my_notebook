Linear Regression & Its Assumptions

№ 3 · machine learning · regression

The goal of linear regression is deceptively simple: find the straight line that best fits the data — the line that minimises the sum of squared errors between what the model predicts and what actually happened. The equation is $y = mx + c$, generated from historical data.

Before applying any model, one must perform EDA — exploratory data analysis. The method rests on five assumptions:

→ Linearity — the relationship between x and y must be linear.

→ Homoscedasticity — the error term must have constant variance. (Residual analysis explores this visually.)

→ Independence — error terms should be independent of each other.

→ Normality — error terms should be normally distributed, with mean of residuals ≈ 0.

→ No multicollinearity — independent variables should have no relation to each other.
