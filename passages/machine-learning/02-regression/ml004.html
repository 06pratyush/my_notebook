Residual Analysis

№ 4 · machine learning · diagnostics

A residual is the gap between what the model predicted and what actually happened — the error for a single observation. Plot every residual against the input variable x, and the resulting scatter plot tells you whether the assumptions of linear regression hold or have been violated.

In a homoscedastic plot, the residuals scatter uniformly — a flat band of noise with no pattern. The error does not change with change in x. This is what you want: the model's mistakes are evenly distributed.

In a heteroscedastic plot, the residuals fan out — the error grows wider (or narrower) as x increases. The spread is not constant; the model is more confident in some regions and less in others. When this pattern appears, the standard errors are wrong and the model needs attention.
