Performance Metrics

№ 5 · machine learning · evaluation

How do you judge a model's worth? Not by how well it fits the training data — any model can memorise — but by how honestly it captures the underlying structure. Several metrics exist for this, each illuminating a different facet of performance.

The most common starting point is the coefficient of determination, $R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$, which lies between 0 and 1. A value of 1 means the model explains all the variance; 0 means it does no better than predicting the mean. It is also called the goodness of fit. When the number of predictors grows, however, $R^2$ is misleading — it can only go up, even with useless variables. The adjusted $R^2$ corrects for this: $R^2_{adj} = 1 - \frac{(1 - R^2)(n - 1)}{n - k - 1}$, where $n$ is the number of observations and $k$ the number of input dimensions. Penalising each extra variable, it only improves when the new term actually helps.

From the errors themselves, the mean squared error takes the average of squared residuals: $MSE = \frac{1}{N}\sum(y_i - \hat{y}_i)^2$. Squaring punishes large errors more than small ones, making the metric sensitive to outliers. Its square root, the root mean squared error, $RMSE = \sqrt{MSE}$, brings the error back into the original units of $y$ — interpretable and comparable to the data itself. For a measure more robust to outliers, the mean absolute error uses absolute deviations instead: $MAE = \frac{1}{N}\sum|y_i - \hat{y}_i|$, which treats all errors linearly.

Finally, the Pearson correlation coefficient $r = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2 \cdot \sum(y_i - \bar{y})^2}}$ measures how two variables move together, ranging from $-1$ (perfect inverse) to $+1$ (perfect positive). It captures linear association, not causation, and is silent on nonlinear relationships. Together, these metrics form the vocabulary of model evaluation — each one a different lens on the same question: how close are the predictions to reality?
