Types of Machine Learning

№ 2 · machine learning · taxonomy

Machine learning splits into three great families, and the difference between them is simply what the data carries with it when it arrives.

Supervised learning — the data is labelled. Each input comes paired with the correct answer, and the model's job is to learn the mapping from one to the other. Classification and regression both live here. The teacher has already marked the answers; the model merely studies them.

Unsupervised learning — the data is unlabelled. No answers arrive; only inputs. The central focus becomes similarity: which data points cluster together, which variables move in lockstep. K-means, PCA, and hierarchical clustering are its tools.

Reinforcement learning — an agent acts in an environment and receives rewards or penalties. There is no fixed dataset; instead, the agent learns by doing, maximising cumulative reward over time. Game-playing AIs, robotics, and adaptive recommendation engines belong here.
