The Phases of Machine Learning

№ 1 · machine learning · ML pipeline

Every machine learning project follows the same skeleton: a dataset is split, a model is built, and its worth is judged. The pipeline has three phases — Train, Test, and Evaluate — and the order is not negotiable.

The training set feeds model development — the algorithm learns its patterns there. The test set is held back entirely; once the model is built, it faces the test set cold, and predictions are made on data it has never seen. The evaluation phase then judges performance: how far the predictions stray from reality.

The standard split is 70% Train, 30% Test. What matters is the principle: the model must never peek at the test data during training, or the evaluation is a lie. Train first, test after, evaluate last. The types of learning in Types of Machine Learning determine what happens inside each phase.
